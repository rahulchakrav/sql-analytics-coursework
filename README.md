# SQL Analytics Coursework

SQL coursework by Rahul Chakravarty, an M.S. in Information Systems student concentrating in Data Analytics at Baruch College.

This repository presents selected work from **CIS 9440 — Data Warehousing and Analytics**. The first entry focuses on joining tables, aggregating records, calculating data quality measures, and producing analytical summaries.

## Demonstrated techniques

- INNER and LEFT JOINs, including joins on multiple keys
- Common table expressions (CTEs)
- GROUP BY, HAVING, and ORDER BY
- Conditional aggregation with COUNTIF
- CASE expressions, NULL checks, and COALESCE
- Calculated percentages with SAFE_DIVIDE
- Date parsing and extraction
- Correlation calculations with CORR

## Context and attribution

This is academic coursework, not a business deployment. The dataset, table structure, and analytical questions were supplied through the course. The queries are selected from my submitted first homework assignment.

The portfolio copy omits the assignment prompts, the supplied starter query in part (i), and the instructor-provided example query in part (l). The retained SQL answers have not been changed; section headings were added and prompt comments removed.

The source data and query outputs are not included. This repository makes no claims about measured business impact or verified analytical findings.
